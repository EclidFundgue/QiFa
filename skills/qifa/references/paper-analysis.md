# 论文分析（source-analysis 前半）

目标：把论文变成 `source/source-model.json` 里可引用、可核查的结构化来源。**只读来源，不臆造内容。**

## 载体与处理顺序

| 载体 | 获取方式 | 备注 |
| --- | --- | --- |
| arXiv URL | 优先下载 e-print LaTeX 源码存 `source/paper-src/`，缺失时回落 PDF | 源码最利于公式与图表还原 |
| 本地 PDF | `pdftotext -layout` 抽文本；`pdfplumber` 补表格/坐标；图片用 `pdftocairo`/`pdfimages`（有则用） | 无文本层（扫描件）→ 降级：只用图表与人工概述，并记 warning |
| 本地 LaTeX 工程 | 直接读 `.tex`、`.bib`、图片目录 | 章节/公式/图表编号天然可用 |
| DOCX | `python-docx`；缺失则提示安装或让用户导出 PDF | 编号可能丢失，引用改用章节标题 |
| 网页文章 | 用 Agent 抓取正文（`urllib`/`requests`），清理导航与脚本 | 无页码，引用改用小节标题 |

抽取工具链遵循"探测已装库、缺库优雅降级"；任何一项降级都写入 `run-state` 的 `degradations`。

## 抽取顺序

1. **元信息**：标题、作者、年份、发表处。
2. **研究问题**：论文要解决什么，此前方法差在哪。
3. **方法**：核心思路、关键模块、必要公式（LaTeX 原文优先）。
4. **实验**：数据集、基线、指标、主结果表、消融。
5. **证据边界**：作者主张 vs 实验支持；哪些结论只在特定条件下成立。
6. **资产**：图、表、公式、重要原文引用，逐条编号并记录页码。

## 映射到 `source-model.json`

- `sources[]`：一条 `type: paper`，含 `sections[] / figures[] / equations[] / tables[]`（`id` 用论文自身编号，如 `Fig.2`、`Eq.3`）。
- `glossary[]`：领域术语与缩写，`translation` 为目标语言译名。
- 混合输入时写 `relevance.mapping`（`paper_section` ↔ `code_paths`）。

## 引用格式

- 论文编号为主、页码为辅：`[Fig.2, p.7]`、`[Eq.3, p.4]`、`[§4.1, p.6]`。
- 引用必须能在 `source-model` 里找到对应条目；找不到就删掉或标注不确定。
- 数值结果引用必须带条件（数据集/指标），不得只写"效果很好"。

## 红线

- 不夸大贡献：不用"革命性/首次"等词，除非论文原文如此且标注出处。
- 不编造公式、页码、图表编号、实验数字。
- 不确定的地方显式写"论文未说明/来源不可得"。

## 自检清单

- [ ] 每个 `sections/figures/equations/tables` 条目都能在原论文中找到。
- [ ] 页码使用 PDF 物理页，编号使用论文自身编号。
- [ ] 关键公式保留 LaTeX 原文；无法提取的公式已记 warning。
- [ ] 实验结论区分"作者主张"与"数据支持"。
- [ ] `glossary` 覆盖所有首次出现的缩写。
